# Coding Problems

50 classic coding problems. Each file contains the full challenge as a header
comment — statement, constraints, worked examples, edge cases, and the naive vs.
target complexity — followed by an empty stub for you to fill in.

**15 Easy · 29 Medium · 6 Hard**

## How to practice

```bash
git clone <this-repo> && cd coding_problems
```

Open any file, read the header, and replace `// TODO` with your solution.
Work top to bottom within a topic — problems are ordered by difficulty inside each folder.
